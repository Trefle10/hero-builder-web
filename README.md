# Hero Builder (web)

Draw your own 48x64 hero, layer by layer (head, torso, arms, legs, hair…), recolour it, and
animate poses (idle, walk, run, attack, hurt, KO, cast). Made for **Dad Master Framework** (DMF).

**Play:** https://trefle10.github.io/hero-builder-web/

- **English / Français:** use the language button (top left).
- **Save hero:** downloads `hero_<name>_<date>.zip`. Give that zip to Dad so the hero can go into
  the game. Your drawing is also autosaved in the browser and comes back when you reopen the page.
- **Open a .zip or .png:** keep working on a saved hero, or load a drawing.
- **Copy hero code / Paste hero code:** share a hero as text in a chat message (long heroes are
  split into parts; paste all of them, in any order).

---

**Créateur de héros (web)** : dessine ton héros 48x64 calque par calque, change ses couleurs et
anime ses poses. Bouton **Français / English** en haut à gauche. **Sauvegarder le héros** télécharge
un fichier `.zip` à donner à papa pour le mettre dans le jeu ; ton dessin est aussi sauvegardé
automatiquement dans le navigateur.

Built with Godot 4.7.2 (web export, single-threaded, so no special server headers are needed).
This repository contains only the exported build.
